# Template provenance

This directory is a verbatim working copy of the ClassicThesis bundle obtained
from a ZIP file provided by the university library. It identifies itself as
ClassicThesis 4.8, dated February 2025.

The bundle is preserved for reproducible thesis typesetting. Its contents are
generic ClassicThesis examples and documentation; they are not, by themselves,
verified university submission requirements. Confirm institutional rules before
adapting the template. Upstream licensing is retained in `COPYING`.
